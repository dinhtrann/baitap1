# 2.1.2 Đăng Nhập - User Login Flow

## Mô tả
Tính năng cho phép người dùng đăng nhập vào hệ thống bằng email và mật khẩu.

**Actor:** Mọi người  
**Mã số:** 2.1.2

## Flowchart

```mermaid
flowchart TD
    Start([User truy cập trang đăng nhập]) --> ShowForm[Hiển thị form đăng nhập]
    ShowForm --> InputCredentials[User nhập:<br/>- Email<br/>- Mật khẩu]
    InputCredentials --> ValidateFormat{Kiểm tra định dạng}
    
    ValidateFormat -->|Email không hợp lệ| ErrorEmailFormat[Hiển thị lỗi:<br/>Email không đúng định dạng]
    ErrorEmailFormat --> InputCredentials
    
    ValidateFormat -->|Mật khẩu <8 hoặc >16 ký tự| ErrorPasswordFormat[Hiển thị lỗi:<br/>Mật khẩu không hợp lệ]
    ErrorPasswordFormat --> InputCredentials
    
    ValidateFormat -->|Định dạng hợp lệ| CheckUser{Kiểm tra user<br/>trong database}
    
    CheckUser -->|Email không tồn tại| ErrorUserNotFound[Hiển thị lỗi:<br/>Email hoặc mật khẩu không đúng]
    ErrorUserNotFound --> InputCredentials
    
    CheckUser -->|Email tồn tại| CheckPassword{So sánh mật khẩu}
    
    CheckPassword -->|Mật khẩu sai| ErrorWrongPassword[Hiển thị lỗi:<br/>Email hoặc mật khẩu không đúng]
    ErrorWrongPassword --> InputCredentials
    
    CheckPassword -->|Mật khẩu đúng| CheckStatus{Kiểm tra trạng thái<br/>tài khoản}
    
    CheckStatus -->|Tài khoản bị vô hiệu hóa| ErrorDisabled[Hiển thị lỗi:<br/>Tài khoản đã bị vô hiệu hóa]
    ErrorDisabled --> End([Kết thúc])
    
    CheckStatus -->|Tài khoản chưa xác nhận| ErrorPending[Hiển thị lỗi:<br/>Tài khoản chưa được xác nhận]
    ErrorPending --> End
    
    CheckStatus -->|Tài khoản hoạt động| CreateToken[Tạo JWT token<br/>thời hạn 24h]
    CreateToken --> CheckToken{Token tạo thành công?}
    
    CheckToken -->|Lỗi tạo token| ErrorToken[Hiển thị lỗi:<br/>Lỗi hệ thống, thử lại sau]
    ErrorToken --> InputCredentials
    
    CheckToken -->|Thành công| SaveSession[Lưu session]
    SaveSession --> CheckRole{Kiểm tra vai trò}
    
    CheckRole -->|Reader| RedirectReader[Chuyển hướng đến<br/>Dashboard Độc giả]
    CheckRole -->|Librarian| RedirectLibrarian[Chuyển hướng đến<br/>Dashboard Nhân viên]
    CheckRole -->|Admin| RedirectAdmin[Chuyển hướng đến<br/>Dashboard Quản lý]
    
    RedirectReader --> End
    RedirectLibrarian --> End
    RedirectAdmin --> End
    
    InputCredentials -->|User hủy| Cancel[Đóng form]
    Cancel --> End
```

## Validation Rules

- **Email:** Định dạng email hợp lệ
- **Mật khẩu:** Không được để trống, tối thiểu 8 ký tự, tối đa 16 ký tự

## Session Management

- JWT token được tạo với thời hạn: **24 giờ**
- Token được lưu trong session/cookie để xác thực các request tiếp theo

## Redirect Logic

Sau khi đăng nhập thành công, user được chuyển hướng đến dashboard tương ứng với vai trò:
- **Reader** → Dashboard Độc giả
- **Librarian** → Dashboard Nhân viên thư viện
- **Admin** → Dashboard Quản lý viên
