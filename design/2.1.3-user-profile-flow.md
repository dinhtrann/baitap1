# 2.1.3 Hồ Sơ Cá Nhân - User Profile Flow

## Mô tả
Tính năng cho phép độc giả xem và cập nhật thông tin cá nhân, thay đổi mật khẩu.

**Actor:** Độc giả  
**Mã số:** 2.1.3  
**Yêu cầu:** Đăng nhập với vai trò độc giả

## Flowchart - Xem Hồ Sơ

```mermaid
flowchart TD
    Start([Độc giả truy cập trang Hồ sơ]) --> CheckAuth{Kiểm tra đăng nhập}
    
    CheckAuth -->|Chưa đăng nhập| RedirectLogin[Chuyển hướng đến<br/>trang đăng nhập]
    RedirectLogin --> End([Kết thúc])
    
    CheckAuth -->|Đã đăng nhập| CheckRole{Kiểm tra vai trò}
    
    CheckRole -->|Không phải Reader| ErrorUnauthorized[Hiển thị lỗi:<br/>Không có quyền truy cập]
    ErrorUnauthorized --> End
    
    CheckRole -->|Là Reader| LoadProfile[Tải thông tin hồ sơ]
    LoadProfile --> DisplayInfo[Hiển thị thông tin:<br/>- Tên, Email<br/>- Số điện thoại, Địa chỉ<br/>- Ngày tham gia<br/>- Số lần mượn<br/>- Tổng số tiền phạt]
    DisplayInfo --> ShowActions[Hiển thị các nút:<br/>- Cập nhật thông tin<br/>- Thay đổi mật khẩu]
    ShowActions --> End
```

## Flowchart - Cập Nhật Thông Tin

```mermaid
flowchart TD
    Start([Click Cập nhật thông tin]) --> ShowForm[Hiển thị form chỉnh sửa]
    ShowForm --> InputData[User nhập thông tin mới:<br/>- Tên<br/>- Số điện thoại<br/>- Địa chỉ]
    InputData --> Validate{Kiểm tra validation}
    
    Validate -->|Tên để trống hoặc >50 ký tự| ErrorName[Hiển thị lỗi:<br/>Tên không hợp lệ]
    ErrorName --> InputData
    
    Validate -->|Số điện thoại không đúng định dạng| ErrorPhone[Hiển thị lỗi:<br/>Số điện thoại không hợp lệ]
    ErrorPhone --> InputData
    
    Validate -->|Địa chỉ để trống hoặc >255 ký tự| ErrorAddress[Hiển thị lỗi:<br/>Địa chỉ không hợp lệ]
    ErrorAddress --> InputData
    
    Validate -->|Tất cả hợp lệ| UpdateDB[Cập nhật database]
    UpdateDB --> CheckUpdate{Kiểm tra kết quả}
    
    CheckUpdate -->|Lỗi| ErrorDB[Hiển thị lỗi:<br/>Lỗi hệ thống]
    ErrorDB --> InputData
    
    CheckUpdate -->|Thành công| Success[Hiển thị thông báo:<br/>Cập nhật thành công]
    Success --> Refresh[Làm mới trang hồ sơ]
    Refresh --> End([Kết thúc])
    
    InputData -->|Hủy| Cancel[Đóng form]
    Cancel --> End
```

## Flowchart - Thay Đổi Mật Khẩu

```mermaid
flowchart TD
    Start([Click Thay đổi mật khẩu]) --> ShowForm[Hiển thị form đổi mật khẩu]
    ShowForm --> InputOld[User nhập mật khẩu cũ]
    InputOld --> CheckOld{So sánh mật khẩu cũ}
    
    CheckOld -->|Mật khẩu cũ sai| ErrorOldPassword[Hiển thị lỗi:<br/>Mật khẩu cũ không đúng]
    ErrorOldPassword --> InputOld
    
    CheckOld -->|Mật khẩu cũ đúng| InputNew[User nhập:<br/>- Mật khẩu mới<br/>- Confirm mật khẩu mới]
    InputNew --> Validate{Kiểm tra validation}
    
    Validate -->|Mật khẩu mới <8 hoặc >16 ký tự| ErrorPasswordLength[Hiển thị lỗi:<br/>Mật khẩu không hợp lệ]
    ErrorPasswordLength --> InputNew
    
    Validate -->|Confirm mật khẩu không khớp| ErrorConfirm[Hiển thị lỗi:<br/>Mật khẩu xác nhận không khớp]
    ErrorConfirm --> InputNew
    
    Validate -->|Mật khẩu mới = mật khẩu cũ| ErrorSame[Hiển thị lỗi:<br/>Mật khẩu mới phải khác mật khẩu cũ]
    ErrorSame --> InputNew
    
    Validate -->|Tất cả hợp lệ| HashPassword[Mã hóa mật khẩu mới]
    HashPassword --> UpdateDB[Cập nhật mật khẩu trong database]
    UpdateDB --> CheckUpdate{Kiểm tra kết quả}
    
    CheckUpdate -->|Lỗi| ErrorDB[Hiển thị lỗi:<br/>Lỗi hệ thống]
    ErrorDB --> InputNew
    
    CheckUpdate -->|Thành công| Success[Hiển thị thông báo:<br/>Đổi mật khẩu thành công]
    Success --> Logout[Yêu cầu đăng nhập lại]
    Logout --> End([Kết thúc])
    
    InputNew -->|Hủy| Cancel[Đóng form]
    Cancel --> End
```

## Validation Rules

- **Tên:** Không được để trống, tối đa 50 ký tự
- **Số điện thoại:** Định dạng số điện thoại hợp lệ
- **Địa chỉ:** Không được để trống, tối đa 255 ký tự
- **Mật khẩu mới:** Tối thiểu 8 ký tự, tối đa 16 ký tự, phải khác mật khẩu cũ

## Thông Tin Hiển Thị

- Tên, Email, Số điện thoại, Địa chỉ
- Ngày tham gia
- Số lần mượn
- Tổng số tiền phạt
